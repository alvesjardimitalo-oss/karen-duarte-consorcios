# Karen Duarte Martins - Consórcios de Cosméticos

Plataforma responsiva (desktop e celular) para gerenciamento de turmas de consórcio de cosméticos.

## Regra central

- Turmas com participantes e parcelas mensais.
- Exemplo: 10 participantes x R$ 35,00 = R$ 350,00 de crédito mensal em produtos.
- A cliente contemplada continua pagando todas as parcelas restantes.
- O crédito pode ser utilizado em uma ou várias retiradas.
- Se os produtos ultrapassarem o saldo do voucher, a diferença é paga via PIX.
- Pagamento de parcela e pagamento complementar de produtos são operações independentes.

## Módulos previstos

- Autenticação e usuários
- Clientes
- Turmas/Consórcios
- Participantes
- Parcelas
- Pagamentos
- Sorteios
- Contemplações
- Fornecedores e produtos
- Vouchers e resgates
- PIX complementar
- Notificações
- Auditoria
- Dashboard e relatórios

## Arquitetura

O projeto será organizado por módulos para que alterações em uma funcionalidade fiquem concentradas nos arquivos do módulo afetado, reduzindo acoplamento e risco de regressões.

## Identidade visual

Tema principal em rosa claro e branco, baseado na identidade Karen Martins Cosméticos, com interface responsiva e foco em uso simples no celular.
